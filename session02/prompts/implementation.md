# 第2回: AIエージェントへの実装プロンプト例

テーマは「Excel読み取りと集計の自動化」です。保存済みのExcelを読み直し、列選択・データ整形・グループ集計・Excel出力を順に体験します。

```text
Pythonとpandas、openpyxlを使い、次の2つのスクリプトを実装してください。

要件:
- create_sales_data.py
  - 3店舗（東京駅前店、横浜店、大宮店）×3日（2026年11月1日〜3日）×5品目の架空売上明細45件を作る
  - 品目と単価は、コーヒー豆1200円、緑茶800円、クッキー450円、マグカップ1500円、ドリップバッグ600円とする
  - 日・店舗・品目をそれぞれ0から数え、数量は (日番号 + 店舗番号 + 品目番号) % 4 + 1 とする
  - 何度実行しても同じサンプルデータを作る
  - input/売上データ.xlsx の「売上明細」シートに保存する
  - 見出しは、日付、店舗、品目、単価、数量の5列とし、備考列は作らない
  - 入力・出力ExcelはYu Gothicの11ポイント、行高22、列幅22、薄い灰色の罫線で統一する
  - 見出しは太字・灰色背景・左寄せ、明細は白背景・上下中央揃え・折り返しなしにする
  - 日付は中央揃えでyyyy-mm-dd、店舗・品目は左寄せ、数値列は右寄せで#,##0にする
  - 数値を文字列として保存したサンプルにも同じ表示書式を設定し、練習用の値と型は維持する
  - 整形を体験できるよう、1日目の明細の直後に全列が空欄の行を1行入れる
  - 各店舗・日の最初の品目について、店舗名の前後に半角空白を入れ、単価と数量を文字列にする
  - 東京駅前店の品目名の前後に全角空白を入れる
  - 既存の入力Excelは、--overwrite を指定した場合だけ上書きする
- aggregate_sales.py
  - 保存済みの input/売上データ.xlsx を pandas.read_excel で必ず読み直す
  - データ生成時のメモリ上の明細を流用しない
  - 「売上明細」シートの列を番号ではなく見出し名で特定する
  - 必須列は、日付、店舗、品目、単価、数量とする
  - 全列が空欄の行を除外し、必須5列だけを選択する
  - 店舗名と品目名の前後の半角・全角空白を除く
  - 日付を日単位に統一し、単価と数量を整数に変換する
  - 売上金額 = 単価 × 数量 の列を追加する
  - 整形済み明細を日付・店舗・品目順に並べる
  - 店舗別、日別・店舗別、品目別に数量と売上金額を合計する
  - output/売上集計.xlsx に次の4シートを保存する
    整形済み明細、店舗別集計、日別店舗別集計、品目別集計
  - 入力Excelは変更しない
  - 入出力パスはスクリプトの場所を基準にし、実行時の作業ディレクトリに依存させない
  - 各シートの見出し行を固定し、フィルターを設定する
  - 出力Excelの列幅を22にし、単価・数量・売上金額は桁区切りで表示する
  - 明細数、売上合計、店舗別集計、出力先を標準出力に表示する
- エラーの扱い
  - 必須列の欠落、明細なし、店舗・品目の空欄、不正な日付を検出する
  - 単価と数量は0〜1,000,000の整数だけを許可する
  - 不正な明細は黙って除外せず、集計Excelを保存する前に処理を止める
  - 入力ファイルなし、シートなし、壊れたExcel、読取・書込権限の問題を日本語で案内する
- コードの構成と説明
  - データ作成は create_sample、集計は load_sales、clean_sales、summarize_sales、write_report に分ける
  - 各import行の直前に、標準ライブラリか追加ライブラリか、およびこのコードでの用途を日本語コメントで説明する
  - 使用するライブラリの役割と、読み込むクラス・機能の用途を説明する。標準ライブラリは追加導入不要、pandasとopenpyxlはrequirements.txtで導入することを明記する
  - 各関数の先頭に、日本語docstringで入力（引数やファイル）と出力（戻り値・保存ファイル・画面表示）を説明する
  - main関数の処理ステップには、各処理行の直前に1行ずつ日本語の説明コメントを付ける
  - 条件分岐と例外処理についても、条件・エラー時の動作を説明する
  - Python 3.8以降でも使える記法を維持する
  - requirements.txt に依存パッケージを記載する
- 検証
  - python3.14 -m py_compile で両スクリプトの構文を確認する
  - 仮想環境に依存を導入し、サンプル生成と集計の両コマンドを実行する
  - 整形済み明細45行、店舗別3行、日別店舗別9行、品目別5行、出力4シートを確認する
  - 元明細から独立に数量・売上合計を計算し、各集計表の合計と一致することを確認する
  - 入力Excelが集計前後で変更されていないことを確認する
  - 必須列の欠落や不正な値で、エラーになり新しい集計Excelが保存されないことを確認する
  - 異常系の検証には一時ファイルを使い、サンプルを壊さない

作業を始める前に既存ファイルと構成を確認してください。
実装後はサンプルデータを使ってコマンドを実行し、各出力を確認してください。
実データや個人情報を外部サービスへ送信しないでください。
```
