# AIエージェントへの実装プロンプト例

以下を実装依頼のたたき台として使います。入力ファイルの形式、集計ルール、出力先、異常時の扱い、検証方法を具体的に指定しています。

```text
Pythonとopenpyxlを使い、同じフォルダの「output/売上データ.xlsx」を読み込む日次売上レポートを実装してください。

要件:
- Excelには3店舗×3日分の9シートがあり、各シートの1行目は次の見出しです。
  日付、店舗、顧客ID、品目、単価、数量、売上金額
- 列番号ではなく見出し名で項目を特定する
- 各店舗・各日の売上金額、顧客IDのユニーク件数、品目別販売数量を集計する
- 店舗・日別の集計結果を含むExcelを output/売上報告.xlsx に保存する
- 各日1ページのPDFを output/日次売上レポート.pdf に保存する
  - 1店舗ごとに売上金額、顧客数、販売個数上位3品目を表示する
- 各日1行で3店舗の売上金額と全店の販売個数上位3品目をまとめ、
  output/上司向け日報.txt に保存する
- 元の入力Excelを変更しない
- 必須シート数、見出し、明細の不足を検出し、対象シート名を含むエラーを表示する
- コードの主要な処理には、初学者にも流れが分かる日本語コメントを付ける
- 合成データで、シート数・顧客数・売上合計・上位品目を検証する
- 実行手順と生成ファイルを README.md に記載する

作業を始める前に既存ファイルと構成を確認してください。
実装後はサンプルデータを使ってコマンドを実行し、各出力を確認してください。
実データや個人情報を外部サービスへ送信しないでください。
```
