# AIエージェントへの実装プロンプト例

以下を実装依頼のたたき台として使います。入力ファイルの形式、集計ルール、出力先、異常時の扱い、検証方法を具体的に指定しています。

```text
Pythonとopenpyxlを使い、次の2つのスクリプトを実装してください。

要件:
- create_sales_data.py
  - 3店舗×3日分、各店舗・日ごとに10顧客分の架空売上明細を作る
  - 商品は5品目、顧客1人あたり1〜3品目、数量は1〜4個とする
  - 乱数シードを固定し、何度実行しても同じデータを作る
  - 店舗・日別のTSV 9件と、9シートの output/売上データ.xlsx を作る
- generate_sales_report.py
  - create_sales_data.py が保存した output/売上データ.xlsx を必ず読み直して処理する
  - PDF用データを生成時のメモリ上の明細から流用しない
- Excelには3店舗×3日分の9シートがあり、各シートの1行目は次の見出しです。
  日付、店舗、顧客ID、品目、単価、数量、売上金額
- 列番号ではなく見出し名で項目を特定する
- 各店舗・各日の売上金額、顧客IDのユニーク件数、品目別販売数量を集計する
- 店舗・日別の集計結果を含むExcelを output/売上報告.xlsx に保存する
- 各日1ページのPDFを output/日次売上レポート.pdf に保存する
  - 1店舗ごとに売上金額、顧客数、販売個数上位3品目を表示する
- PDFは1日1ページで全3ページとし、各ページに3店舗それぞれの売上金額、顧客数、販売個数上位3品目をまとめる
- 各日の上司向け要約を1日3行程度で output/上司向け日報.txt に保存する
  - 店舗別売上
  - 全店売上と顧客数
  - 販売個数上位3品目
- 元の入力Excelを変更しない
- 必須シート数、見出し、明細の不足を検出し、対象シート名を含むエラーを表示する
- コードの主要な処理には、初学者にも流れが分かる日本語コメントを付ける
- Python 3.8以降を想定し、requirements.txt を使った仮想環境の作成・依存導入手順をREADME.mdに記載する
- 合成データで、シート数・顧客数・売上合計・上位品目・PDFのページ数・要約行数を検証する
- 実行手順と生成ファイルを README.md に記載する

作業を始める前に既存ファイルと構成を確認してください。
実装後はサンプルデータを使ってコマンドを実行し、各出力を確認してください。
実データや個人情報を外部サービスへ送信しないでください。
```
